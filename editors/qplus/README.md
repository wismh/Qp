# Q+

Syntax highlighting and `qpc lsp` for [Q+](https://github.com/wismh/Qp) (`.qp` files).

This folder is a VS Code / Cursor extension (grammar + `qpc lsp` client) and a TextMate bundle for CLion highlighting. CLion hints come from [`editors/clion/`](../clion/). See [`editors/README.md`](../README.md).
